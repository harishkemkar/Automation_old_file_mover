Run image using docker on vs code terminal which is power shell  

docker run -v ${PWD}/Source:/app/Source -v ${PWD}/Target:/app/Target automation-old-file-mover:latest


run command with port mapping 

docker run -p 5000:5000 -v ${PWD}/Source:/app/Source -v ${PWD}/Target:/app/Target automation-old-file-mover:latest


Command to buid image --   
docker build -t automation-old-file-mover .

Command to run image   
docker run -p 5000:5000 -v ${PWD}/Source:/app/Source -v ${PWD}/Target:/app/Target automation-old-file-mover:latest

To check running App in browser   

http://127.0.0.1:5000/
